02 · Checklist

Checklist deployment EC2

Sembilan langkah dari instance kosong sampai bisa diakses lewat IP publik. Centang setiap langkah setelah benar-benar diverifikasi dari luar server.

Progres

0 / 9 langkah selesai

Verifikasi wajib. Buka dari perangkat lain (HP dengan data seluler) menggunakan IP publik. Jika hanya bisa dibuka di laptop yang sama, berarti masih mengakses localhost atau tunnel lokal, bukan EC2.

03 · Data

Database workspace

Catatan konfigurasi database untuk lab Next.js/PostgreSQL. Form ini menyusun DSN dan menyimpannya di browser; tidak ada koneksi jaringan yang dibuka dari halaman statis ini.

Konfigurasi koneksi

Nilai default mengikuti lab lokal

PostgreSQL 16

DSN yang dihasilkan

Password disamarkan pada tampilan

postgresql://ec2lab:••••••@127.0.0.1:5433/ec2lab

Perintah uji dari server

EC2 / WSL2# PostgreSQL lokal psql -h 127.0.0.1 -p 5433 -U ec2lab -d ec2lab # dari container docker exec -it uts-db psql -U ec2lab -d ec2lab -c '\dt' # tes port tanpa client nc -vz 127.0.0.1 5433
Aturan aman. Database tidak boleh mendengar di 0.0.0.0 pada instance publik. Bind ke 127.0.0.1 atau letakkan di subnet privat dan akses lewat Security Group.

04 · Delivery

Pipeline configurator

Pilih komponen, lalu lihat alur deploy yang terbentuk. Pilihan disimpan di browser dan bisa dipakai sebagai bahan narasi video.

Alur yang terbentuk

Contoh workflow GitHub Actions

.github/workflows/deploy-ec2.ymlon: push: branches: [main] jobs: deploy: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - name: Build image run: docker build -t app:${{ github.sha }} ./app - name: Deploy via SSH run: | echo "${{ secrets.EC2_SSH_KEY }}" > key chmod 600 key rsync -avz -e "ssh -i key" \ ./index.html ./assets ./knowledge.html \ ./login.html ./dashboard.html \ ubuntu@${{ secrets.EC2_HOST }}:/var/www/uts/

Keputusan yang harus dicatat

  • Mengapa Nginx, bukan Apache2?
  • Mengapa satu EC2, bukan container orchestration?
  • Di mana state Terraform disimpan?
  • Bagaimana rollback jika deploy gagal?
  • Bagaimana kredensial disimpan dan dirotasi?
  • Siapa yang menerima alert jika situs mati?

Jawaban singkatnya ada di bagian CI/CD knowledge base.
